Quantum Fundamentals

The four ideas everything else in this course builds on.

What is quantum computing?

A quantum computer stores and processes information using qubits instead of bits. Instead of following one path through a problem, it lets many possibilities interfere with each other, which is useful for a narrow but powerful class of problems.

Qubits

A classical bit is 0 or 1. A qubit's state is described by two complex numbers, its amplitudes, one attached to |0⟩ and one to |1⟩. Squaring an amplitude's size gives the probability of measuring that outcome.

Superposition

A qubit can hold a weighted combination of |0⟩ and |1⟩ at once. It isn't "both at the same time" so much as undecided until measured — the weights determine how the coin lands.

Entanglement

Two qubits can become linked so that measuring one instantly tells you about the other, no matter how the combined state is split apart. Entanglement is the resource behind CNOT gates and most quantum speedups.

02 · Lesson

Quantum Gates

Gates rotate a qubit's amplitudes. Combine them to build any circuit — try them live in the simulator below.

H

Hadamard

Puts a qubit into equal superposition of |0⟩ and |1⟩.

1/√2 [ 1 1 ] [ 1 -1 ]
X

Pauli-X

The quantum NOT gate — flips |0⟩ and |1⟩.

[ 0 1 ] [ 1 0 ]
Y

Pauli-Y

Flips the state and rotates its phase by 90°.

[ 0 -i ] [ i 0 ]
Z

Pauli-Z

Leaves |0⟩ unchanged, flips the phase of |1⟩.

[ 1 0 ] [ 0 -1 ]
RY

RY(θ) rotation

Tilts a qubit by angle θ — the tunable gate variational circuits are built from.

[ cosθ/2 -sinθ/2 ] [ sinθ/2 cosθ/2 ]
⊕

CNOT

Flips a target qubit only if the control qubit is |1⟩. This is how entanglement is created.

|00⟩→|00⟩ |10⟩→|11⟩ |01⟩→|01⟩ |11⟩→|10⟩

04 · Lesson

Quantum Algorithms

What these gate sequences make possible once you scale them up.

Deutsch–Jozsa 1 query

Decides whether a hidden function is constant or balanced in a single evaluation, where a classical computer would need to check over half of its inputs.

Grover's search √N

Finds a marked item in an unsorted list of N items using roughly √N steps, a quadratic speedup over classical search, by repeatedly amplifying the right answer's amplitude.

Quantum Fourier Transform QFT

The quantum analogue of the discrete Fourier transform, and the engine inside Shor's factoring algorithm and quantum phase estimation.

VQE hybrid

The Variational Quantum Eigensolver pairs a parameterized circuit with a classical optimizer to estimate a molecule's lowest energy state — a bridge between today's noisy hardware and useful chemistry.

05 · Lesson

Quantum Machine Learning

Where quantum circuits and machine learning models meet.

Quantum Neural Network

Replaces classical neurons with layers of parameterized rotation and entangling gates, trained by adjusting angles instead of weights.

Quantum Classifier

Encodes data into qubit states, runs a variational circuit, then measures a qubit to output a class label — trained with a parameter-shift gradient rule.

Quantum Kernel

Uses a quantum circuit to map data into a very high-dimensional space, then measures similarity between states — plugging into classical kernel methods like SVMs.

Hybrid ML

Most near-term QML runs a quantum circuit for one part of the model and a classical network for the rest, passing gradients back and forth between them.

Quantum + ML Applications

Where this combination is already being explored in industry and research.
